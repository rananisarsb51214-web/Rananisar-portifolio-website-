# 🚀 RANA NISAR PORTFOLIO WEBSITE BUILDER

AI-Powered Portfolio Website Builder with Firebase, Firestore, GitHub Automation, Google Workspace Integration, Real-Time Sync Engine, Visual Designer, Analytics Dashboard, and Autonomous Deployment System.

---

## 🌟 Overview

RANA NISAR Portfolio Website Builder is a next-generation portfolio creation platform designed for developers, freelancers, agencies, AI founders, creators, and startups.

The platform automatically generates modern portfolio websites with real-time synchronization, GitHub integration, Firebase backend services, Google Workspace automation, and production-ready deployment pipelines.

## 🔥 Installation

### Clone Repository

```bash
git clone https://github.com/your-username/rana-nisar-portfolio-builder.git
```

### Open Directory

```bash
cd rana-nisar-portfolio-builder
```

### Install Dependencies

```bash
npm install
```

### Environment Setup

```env
NEXT_PUBLIC_FIREBASE_API_KEY=
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=
NEXT_PUBLIC_FIREBASE_PROJECT_ID=
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=
NEXT_PUBLIC_FIREBASE_APP_ID=

GOOGLE_CLIENT_ID=
GOOGLE_CLIENT_SECRET=

GITHUB_TOKEN=
```
